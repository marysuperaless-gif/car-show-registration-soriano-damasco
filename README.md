## Run the backend
```bash
cd backend
dotnet restore
dotnet run --project Api
```
Scalar: http://localhost:5205/scalar/v1  (database `carshow.db` is created and seeded automatically)

## Run the frontend
```bash
cd frontend
npm install
npm run dev
```
